# 影之诗byd 免扫码登录器（svs-autologin）

> **影之诗高清版 PC 客户端**（`com.netease.yzs.hd`）的本地自动扫码登录工具。
> Windows 10/11 x64 · 数据全部留在本机 · 开源可审计

用手机扫码授权**一次**，之后启动游戏自动完成登录，不再需要手机。
所有账号数据、日志、证书都只存在这台电脑上，工具不收集、不上传任何信息。

> ⚠️ **使用前请先读[免责声明](#免责声明)。** 使用第三方登录工具可能违反游戏服务条款，
> 存在封号等风险，后果由使用者自行承担。本项目**不提供账号**，也不绕过任何付费内容。

## 这是什么

影之诗高清版 PC 端的登录流程是：游戏向网易 mkey 申请一个二维码 → 手机 App 扫码确认 →
游戏用二维码会话换票据。本项目在本机复刻「手机扫码确认」这一步：

1. 本机起一个**只监听 127.0.0.1** 的 HTTPS 反向代理，用 hosts 把登录域名指回本机；
2. 拦截游戏的 `create_login`，拿到二维码会话；
3. 用你**本机保存的渠道账号**调用 mkey 的 `scan` + `confirm_login`，顶替手机完成确认；
4. 游戏自己的 `exchange_token` 拿到票据，进入主界面。

命令与流量全部留在本机，运行期不访问任何公网服务（两个 mkey 接口经本地代理转发，
见 [docs/constraints.md](docs/constraints.md) 的 C1 例外）。已移除参考实现中的
远程代码执行（RCE）与云端配置拉取机制。

## 功能

- ✅ 扫码授权一次，之后**免扫码**自动登录
- ✅ 图形界面（PySide6）：启动/停止代理、账号管理、日志页、一键自检、诊断包导出
- ✅ 多账号：账号列表点选即切换默认账号
- ✅ 失败可见：自检七项（配置/账号/**凭据有效期**/hosts/证书/代理/TLS 链路）、弹窗与可读错误
- ✅ 完整回滚：卸载器移除 CA、hosts、快捷方式
- ✅ 零外联（运行期）
- ✅ 协议与密码学细节有文档，开发期 402 项测试把关

## 安装

从 [Releases](../../releases) 下载分发包（或从源码构建，见下文）：

1. 解压到一个**固定目录**（如 `C:\Program Files\svs-autologin`，不要放桌面/下载目录）；
2. 双击 `tools\setup.bat`，UAC 点「是」；也可以直接双击 `svs-autologin.exe`，
   0.2.1 起会检测到「尚未安装」并引导你一键安装；
3. 看到 `install OK` 即完成。

安装器会（全部可逆）：

- 建数据目录 `C:\ProgramData\svs-autologin`（配置/账号/日志/证书）；
- 生成本机专用 mitmproxy CA 并导入系统信任区（解密游戏登录流量用）；
- 在 hosts 增加 `127.0.0.1 service.mkey.163.com`；
- 创建开始菜单快捷方式。

> 杀软/SmartScreen 可能拦截未签名程序。本工具无代码签名，源码全部随包附带，可自行审计。

## 首次使用：扫码授权一次

1. 启动「svs-autologin」；
2. 点「添加账号（扫码）」→ 确认；
3. 打开游戏登录窗，用手机上的 B站 App 扫码并确认（二维码约 3 分钟过期）；
4. 游戏登录成功后，工具会问「设为默认账号？」→ 点「是」。

凭据与这次扫码绑定，**不能**把账号文件拷到另一台电脑使用。

## 日常使用

1. 打开「svs-autologin」；
2. 点 **「启动」**（会做系统检查 → 起代理 → 自检）；
3. **再打开游戏** —— 顺序很重要：游戏必须在代理启动之后打开；
4. 游戏自动登录进主界面。

窗口顶部两行状态：

- `状态：运行中` —— 代理状态；
- `自动登录：已启用 —— 你的账号` —— 真正会不会自动登录（空则去账号列表点一下默认账号）。

代理和窗口是分开的：关掉窗口代理继续跑；重新打开会自动接管。

## 自检与排错

主界面点 **「自检」**，七项检查会直接告诉你哪里不对、怎么修：

| 检查项 | 常见问题 |
|---|---|
| 配置文件 | `config.local.json` 缺失/损坏 → 重跑安装器 |
| 自动登录账号 | 没设默认账号 / 账号不在表里 / 凭据不全 |
| 账号凭据有效期 | B站 access_token 约 **3 天**过期 → 重新扫码（0.2.2 起自检会在到期前 24 小时提示） |
| hosts 重定向 | 条目缺失或没指向 127.0.0.1 |
| mitm CA 证书 | 证书未导入信任区（按**指纹**比对，不是"有 mitmproxy 证书就行"） |
| 本地反向代理 | 未启动 / 443 被占用 |
| TLS 链路 | 反代证书不是本目录 CA 签发 / 系统代理接管 |

更多见 [docs/README-user.md](docs/README-user.md)。遇到问题时用「导出诊断包」——
里面是脱敏日志、打码配置、账号摘要（**不含** token），可以放心外发。

已知顺序问题：**游戏先开、代理后起**时，这一次登录窗口不会被接管。关掉游戏重开即可。

## 隐私与安全

- **不收集任何数据**，没有账号系统、没有遥测、没有云端配置；
- 账号 token、sessionid 以**明文**保存在本机 `C:\ProgramData\svs-autologin\accounts.json`，
  文件随安装器收紧权限；请不要把该目录提交/分享；
- 工具会在本机安装一张 mitmproxy CA 并解密游戏的登录流量（这是实现原理的一部分）；
- 卸载器会把 CA、hosts、快捷方式全部还原；
- 运行期零外联：开发侧有静态扫描 + 离线测试作为红线（测试套件含第三方密钥样本，
  不随本仓库分发）。

需要 Windows + PowerShell + Python 3.12（构建期会下载 embeddable Python 与依赖）：

```powershell

```

测试套件在开发侧维护（含第三方密钥样本，不随公开仓库分发）。

源码树里的 `runtime/`、`dist/`、`config.local.json`、`accounts.json` 均不进版本库。

## 已知限制

- 只支持影之诗高清版 PC（单游戏，不做通用化）；
- 仅 Windows（依赖 hosts、系统证书库、MITM）；
- **扫码凭据（B站 access_token）约 3 天有效**：过期后游戏会提示「登录已失效，请重新扫码登录」，
  需要重新「添加账号」扫一次；0.2.2 起自检会在到期前 24 小时提示；
- 扫码授权绑定单机，换机需重扫；
- 游戏内网络异常/更新可能改变登录流程，工具可能需要跟进；
- 二维码会话约 3 分钟过期，过期需重开登录窗。
