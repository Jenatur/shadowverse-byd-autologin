# svs-autologin 使用手册(最终用户版)

> 本手册面向拿到分发包的普通使用者。开发者文档见仓库根 `README.md`。

## 这是什么

影之诗高清版(PC)的自动登录工具:扫码授权一次,之后启动游戏自动完成
登录,不再需要手机。工作原理是在本机拦截游戏与网易登录服务器之间的
流量,用你保存的登录凭据替你完成扫码握手。

**第一次使用前会弹一份使用须知(四条风险),需要你同意后才能继续。**
请认真读:使用第三方工具有封号风险,后果由使用者自行承担。

## 安装

1. 把 zip 解压到一个**固定位置**(建议 `D:\svs-autologin`,不要放桌面
   或下载文件夹 —— 安装后移动目录会导致快捷方式失效)。
2. 双击 `tools\setup.bat`,弹出的用户账户控制(UAC)点「是」。
   也可以直接双击根目录的 `svs-autologin.exe`:0.2.1 起它会检测到
   「还没安装」并询问是否现在安装(效果与 setup.bat 相同,同样会弹 UAC)。
3. 等安装器跑完,出现 `install OK` 即完成。

> ⚠️ **没安装就双击 exe 会怎样?** 0.2.0 及更早:代理会直接崩溃
> (「代理进程启动失败」),因为数据目录还落在解压目录、没有配置文件。
> 0.2.1 起会先弹「尚未安装」对话框,点「是」走安装,装完自动重开。

安装器做了什么(全部可逆,见「卸载」):

- 建数据目录 `C:\ProgramData\svs-autologin`(配置/账号/日志都放这里,
  与程序目录分离);
- 生成一张本机专用的 mitmproxy CA 证书并装入系统信任区(游戏登录流量
  解密必需);
- 在 hosts 里加一条 `127.0.0.1 service.mkey.163.com`(登录请求指回本机);
- 建开始菜单快捷方式「svs-autologin」。

安装后有两个等效入口:开始菜单快捷方式,或安装根目录的
`svs-autologin.exe`(双击即开界面)。

### 被杀毒软件 / Windows SmartScreen 拦了怎么办

本工具没有代码签名,首次运行大概率被拦。这不是病毒:

- **SmartScreen 蓝框**:点「更多信息」→「仍要运行」;
- **杀软报毒**:把安装目录加入信任区/白名单。工具的全部源码随包附带
  (`svs_autologin\` 与 `tools\` 下都是纯文本 `.py`),可自行审计;
- 校验完整性:对照发布页的 SHA-256 与 zip 文件的哈希一致再装。

## 首次录入账号(每台电脑一次)

1. 开始菜单启动「svs-autologin」。
2. 点「添加账号(扫码)」→ 确认。
3. 打开游戏,出现登录二维码后用**手机上的 B 站账号**(你玩游戏用的
   那个)扫码确认。二维码约 3 分钟过期,过期就重开登录窗再扫。
4. 游戏提示登录成功后,工具会弹「设为默认账号?」→ 点「是」。
5. 完成。以后启动就是全自动。

注意:凭据绑定这台电脑的这次扫码,**不能**把一台电脑上录的账号文件
拷到另一台用(token 与扫码会话绑定,换机会失效)。

## 日常使用

1. 启动「svs-autologin」(工具窗口);
2. 点「启动」—— 工具先检查系统状态(hosts/证书缺失会提示一键修复),
   起代理后自动自检,然后拉起游戏;游戏已在跑则跳过。「设置」页可配置游戏
   程序路径(留空 = 只起代理,自己开游戏);
3. 游戏自动登录进主界面。

窗口顶部有两行状态:

- `状态:运行中` —— 代理本身的状态;
- `自动登录:已启用 —— 你的账号` —— 真正会不会自动登录。

如果第二行是「未设置默认账号」,说明账号记录了但没有被指定为默认:
在账号列表里**点一下**要用的那个(行尾出现 `[默认]`)即可。

**顺序很重要**:先点「启动」,再打开游戏。游戏先开着再点启动的话,
这一次登录窗口不会被接管 —— 关掉游戏重开一次就好。

多账号:账号列表里点选哪个,哪个就是默认(立即记忆)。可以「重命名」
(只改显示名)和「删除」(凭据从本机移除,默认指向自动清空)。

代理和工具窗口是**分开的**:关掉工具窗口,代理继续跑,游戏不受影响;
重新打开工具窗口会自动接管正在跑的代理。

## 排错 / 导出诊断包

遇到问题时:工具 → 「自检」先看六项检查(配置文件 / 自动登录账号 /
hosts / 证书 / 代理 / TLS 链路),每项都写了怎么处理;
还不行就 → 「导出诊断包」→ 把生成的 zip 发给帮你排错的人。

zip 里有:三份运行日志、脱敏后的配置(密钥值打码)、账号摘要(**不含**
token)、系统状态(hosts/证书/端口)。**不含明文凭据**,可以放心外发。

常见问题:

| 症状 | 处置 |
|---|---|
| 端口 443 被占用 | 有别的程序占了 443(常见:其他加速器/代理)。关掉它再点启动 |
| 代理已崩溃 | 看「日志」页最后几行;重启电脑后再试;不行就导出诊断包 |
| 登录窗不出二维码 | 游戏重开一次;hosts/证书被清理工具误删时重跑 setup.bat(幂等) |
| 自动登录失败弹窗 | 按弹窗提示操作(多数是 token 失效 → 重新「添加账号」扫一次) |
| 自动登录报「TLS 校验失败 / 系统代理」 | 关掉 Clash、v2ray 等工具的**系统代理 / TUN 模式**再点「重启代理」(0.2.1 起工具自己会绕开系统代理,但 TUN 模式会连游戏流量一起接管) |
| 二维码一直不动,「自动登录」显示已启用 | 多半是游戏先开了再点启动:关掉游戏,点「启动」,再开游戏 |
| 双击后**完全没有反应**(无窗口、无报错) | 程序目录可能被安全工具/沙箱标成了「低完整性」,进程连日志都写不了。把程序解压到普通目录(如 `C:\Program Files\svs-autologin`)再跑一次安装;0.2.1 起这种情况会弹错误框而不是静默退出 |

## 卸载

管理员 PowerShell 运行:

```
powershell -ExecutionPolicy Bypass -File tools\uninstall.ps1              # 保留账号数据
powershell -ExecutionPolicy Bypass -File tools\uninstall.ps1 -RemoveData  # 连账号数据一起删
```

卸载器会:停代理 → 删 hosts 条目并刷新 DNS → 从系统信任区移除本工具的
CA → 删快捷方式 → 删安装标记。之后删掉程序目录即可。
